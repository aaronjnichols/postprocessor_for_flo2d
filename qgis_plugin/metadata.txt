about=Converts FLO-2D simulation output into production-ready geospatial datasets (Shapefiles, GeoPackages, GeoTIFFs), Excel reports with charts, and PDF visualizations. Processed layers are automatically loaded into QGIS with organized layer groups and optional QML styling.

    Features:
    - Batch processing of multiple FLO-2D project directories
    - Automatic extraction of 30+ FLO-2D input/output file types
    - GeoTIFF raster generation for depth, velocity, elevation, and more
    - Vector layer creation (domain boundary, inflow/outflow, channels, SWMM)
    - Excel spreadsheets with formatted charts
    - PDF cross-section and hydrograph plots
    - Auto-loading results into QGIS with organized layer groups
    - QML style file support
